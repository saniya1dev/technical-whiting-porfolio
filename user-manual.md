# User Manual: Calculator App

## Introduction
This manual explains how to use the Calculator app on your phone.

## Features
- Basic calculations — add, subtract, multiply, divide
- Scientific mode for advanced calculations
- History to view past calculations

## How to Use

1. Open the Calculator app on your phone.
2. Enter the first number using the keypad.
3. Select an operation — +, -, ×, ÷
4. Enter the second number.
5. Tap "=" to see the result.

## Tips
- Swipe left to switch to Scientific mode.
- Tap "C" to clear your calculation.
